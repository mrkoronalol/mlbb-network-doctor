# MLBB Network Doctor

<p align="left"><img src="docs/logo-preview.png" width="120" alt="MLBB Network Doctor"></p>

Диагностика сети и локальный фильтр серверов **Mobile Legends: Bang Bang** для Android.
Приложение поднимает VPN только для MLBB, показывает пинг и маршрут, помогает выбрать
профиль и не пропускает нежелательные матч-серверы. Без удалённого VPN-сервера,
аккаунтов и обязательной аналитики.

- Трафик не уходит третьим лицам: `VpnService` + `sing-box` (libbox), только пакеты
  `com.mobile.legends` и `com.mobilelegends.mi`.
- Правила, история и пинг хранятся на телефоне.
- Отправка анонимной статистики отключается в настройках и очищает локальную очередь.

## Возможности

- **Дашборд**: текущий пинг, статус маршрута (прямой / фильтруется / выключен) и
  выбранный регион. Пинг берётся только с матч-серверов, а не с
  сервисных проб.
- **Фазовая машина**: IDLE → QUEUE → MATCH_FOUND → IN_GAME. В MATCH_FOUND ничего
  не блокируется и не задерживается (подтверждение матча проходит без риска
  dodge); в IN_GAME блок запрещён — только задержка.
- **Отказ по RST**: правила блокировки — `action: reject` (TCP RST + ICMP
  unreachable для UDP); тумблер «Быстрый отказ (RST)» переключает на `drop`.
- **Шейпер задержки (экспериментально)**: локальный SOCKS5-релей задерживает
  UDP-трафик нежелательных регионов на 100–500 мс вместо блокировки, чтобы
  матчмейкер сам выбирал ДВ. Включается режимом «Задерживать» на дашборде.
- **Профили в выпадающем списке**: Авто, Москва, ДВ, Новосибирск, Пользовательский.
  - «Авто» выбирает регион с лучшим измеренным пингом.
  - Москва / Новосибирск / ДВ — allow-only: разрешён выбранный регион, остальные
    матч-порты блокируются.
- **Диагностика пинга** (Монитор): TCP-пробы известных матч-серверов, топ-5 быстрых
  и топ-5 заблокированных текущим профилем.
- **Debug trace** (Настройки → Для разработчиков): логирование контактов
  MLBB-трафика (IP:порт, фаза, протокол) без содержимого пакетов, экспорт JSON и
  кнопка «Проверить гипотезу» (60 секунд сбора в очереди).
- **Логин-пул**: `154.85.91.0/24:10003` разрешается вместе с `.151`, чтобы игра
  входила и вставала в очередь, когда сервер выдаёт `.152/.155/.156/.157`.
  Переключатель — Настройки → Серверы.
- **Мета**: тир-листы S–D с сайта, группировка по линиям, статистика win/pick/ban,
  контрпики, кэш для офлайна и фильтр «Только для высокого пинга».
- **Карточка «Матч найден»** поверх игры: город, IP:порт, профиль, пинг
  (среднее, джиттер, потери), действия «Разрешить 5 мин» / «Заблокировать».
- **Монитор серверов**: IP подключений MLBB, фильтры по регионам, TCP-пинг,
  блокировка IP или /24.
- **Надёжность**: sticky VPN + восстановление после kill, запрос исключения из
  оптимизации батареи и подсказка для realme/OPPO.
- **GeoIP офлайн**, история в Room, резервная копия JSON.
- **Правила с сервера**: подписанный `rules.json` (порты, профили, известные серверы),
  проверка подписи сертификатом APK и обновление раз в сутки.
- **Обновления** через GitHub Releases с загрузкой и установкой APK.

## Установка

1. Скачайте APK из [Releases](https://github.com/mrkoronalol/mlbb-network-doctor/releases/latest).
2. Установите и выдайте разрешение VPN.
3. Для карточки поверх игры разрешите «Поверх других приложений».
4. На Android 13+ разрешите уведомления.
5. Выберите профиль и включите блокировку **до** поиска матча.

APK в Releases подписан release-ключом; GitHub Actions проверяет сборку тестами и lint.
Для обновления поверх версии с той же подписью данные сохраняются.

## Сборка

Требования: JDK 17, Android SDK 35, Git.

```powershell
# libbox.aar не хранится в репозитории из-за размера
powershell -ExecutionPolicy Bypass -File .\scripts\fetch-libbox.ps1

# укажите путь к SDK
"sdk.dir=C\:\\Users\\<user>\\AppData\\Local\\Android\\Sdk" | Set-Content local.properties

.\gradlew.bat :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-arm64-v8a-debug.apk`.

Адрес API сайта задаётся при сборке: `-PmetaApiBase=https://your-domain.com` или в
приложении (Настройки → Для разработчиков).

## Как это работает

1. VPN-сервис перехватывает только трафик MLBB.
2. Разрешённые адреса идут напрямую.
3. Заблокированные адреса уходят в локальный `sink` и не покидают устройство.
4. В allow-only профилях разрешён выбранный регион, остальные матч-порты
   (`10003`, `5000–5058`, `5500–5599`, `10011–10013`, `10063`) блокируются.
5. Логин-пул и сервисные порты (`30021`, `30071`, `30190`, `30220`) не блокируются.

## Ограничения

- Приложение не меняет регион аккаунта и не обходит ограничения издателя.
- Локальная блокировка **не гарантирует** выбор конкретного матч-сервера: игра может
  привязывать часть сокетов к Wi-Fi/мобильной сети, и сервер видит реальный IP.
  Для смены региона нужен внешний релей/выход в нужном регионе или аккаунт этого
  региона.
- **Шейпер задержки — экспериментальный**: гипотеза «игра ранжирует кандидатов по
  пингу до назначения» не подтверждена на устройстве. Сначала включите Debug trace
  и «Проверить гипотезу»; если проб нет — шейпер не поможет.
- Регион аккаунта приложение не меняет. Если аккаунт привязан к Новосибирску,
  задержка может не повлиять на выбор сервера.
- Не использует root: только VpnService и штатные средства sing-box.
- На некоторых прошивках (Xiaomi/Redmi, realme/OPPO) нужно дополнительно разрешить
  автозапуск и фоновую активность.
- Проект не связан с Moonton. Используйте на свой риск.
